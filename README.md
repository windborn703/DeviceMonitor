# DeviceMonitor 设备监控上位机系统

基于 **Qt 6.5 / C++17** 的工业设备实时监控上位机，包含**设备模拟器**与**上位机客户端**两个程序，通过自定义二进制协议在 TCP 上通信。

```
┌──────────────┐   TCP 二进制协议   ┌──────────────────────────┐
│  设备模拟器   │ ◄────────────────► │       上位机客户端        │
│ (虚拟传感器)  │  心跳/数据/指令     │ 实时曲线 / 历史表格 /      │
└──────────────┘                    │ 报警 / 数据记录 / 自动重连 │
                                    └──────────────────────────┘
```

## 功能特性

- **自定义二进制通信协议**：帧头 + 版本 + 类型 + 长度 + 负载 + 校验和，统一大端字节序，纯 C++ 实现与 Qt 解耦
- **粘包/半包处理**：缓冲区累积 + 状态机剥帧（帧头定位、长度约束、校验三重保险）
- **实时曲线**：QPainter 自绘双曲线（温度/压力），环形缓冲 + Y 轴自适应，深色工业风
- **历史数据表格**：Model/View 架构（QAbstractTableModel），超限记录自动标红
- **超限报警**：阈值可配置，超限行标红、状态告警、报警计数
- **数据记录**：采样数据落盘 CSV（Worker + moveToThread 工作线程，磁盘 IO 不阻塞 UI）
- **心跳保活 + 断线重连**：1.5s 心跳 + 6s 看门狗检测假死连接，断线后每 3s 自动重连
- **指令控制**：上位机下发采样周期指令，设备参数校验并回执（指令-响应模式）

## 技术栈

- Qt 6.5.3（Widgets / Network / Core），C++17，CMake + Ninja
- 三层架构：界面层（MainWindow）→ 通信层（DeviceClient）→ 协议层（FrameParser）
- 多线程：Worker Object + moveToThread，跨线程队列信号，线程封闭设计无锁
- 单元测试：协议打包（逐字节断言）、粘包拆包（六场景）

## 通信协议

二进制帧格式（统一大端字节序）：

```
┌──────────┬────────┬────────┬──────────┬──────────┬────────┐
│  帧头     │  版本   │  类型   │ 负载长度  │   负载    │  校验   │
│  2 字节   │ 1 字节 │ 1 字节 │  2 字节   │  N 字节   │ 1 字节 │
│ 0xAA 0x55 │  0x01  │  ...   │          │          │  sum8  │
└──────────┴────────┴────────┴──────────┴──────────┴────────┘
```

| 帧类型 | 值 | 方向 | 说明 |
|---|---|---|---|
| 心跳请求 | 0x01 | 客户端→设备 | 保活探测 |
| 心跳响应 | 0x02 | 设备→客户端 | 保活应答 |
| 数据上报 | 0x03 | 设备→客户端 | 温度/压力采样值 |
| 控制指令 | 0x04 | 客户端→设备 | 如设置采样周期 |
| 控制响应 | 0x05 | 设备→客户端 | 指令执行回执 |

- 校验和：sum8（负载字节之和取低 8 位），不符则丢帧
- 多字节整数与 float 位模式均按大端序列化，跨 CPU 架构安全

## 构建与运行

环境：Qt 6.5.3（MinGW 11.2 64-bit）+ CMake ≥ 3.21 + Ninja

```bash
# 1. 加载工具链环境（Windows Git Bash）
source env.sh

# 2. 配置 + 编译
cmake -S . -B build -G Ninja -DCMAKE_PREFIX_PATH=D:/Qt6/6.5.3/mingw_64
cmake --build build

# 3. 先启动设备模拟器（终端 1）
./build/simulator/DeviceSimulator.exe

# 4. 再启动上位机（终端 2）
./build/client/DeviceMonitorClient.exe

# 5. 单元测试
./build/tests/test_protocol.exe      # 协议打包
./build/tests/test_frame_parser.exe  # 粘包拆包
```

上位机默认连接 `127.0.0.1:8899`。数据记录保存在 `records/` 目录（CSV，Excel 可打开）。

## 面试演示指引

1. 启动模拟器 + 上位机，点击【连接】→ 曲线生长、表格填充
2. 采样周期改 500ms 点【应用】→ 观察数据刷新加速（指令-响应闭环）
3. 温度上限改 25.0 → 温度波动穿越阈值时报警（表格标红、状态告警）
4. 杀掉模拟器进程 → 观察橙色"自动重连中（第 N 次）"计数递增
5. 重启模拟器 → 客户端 3 秒内自动恢复（心跳 + 看门狗 + 重连）
6. 断开后打开 `records/*.csv` 展示数据记录
